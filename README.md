# 彈出廣告自動關閉

通用型無障礙服務：自動點擊畫面上的「跳過／關閉」按鈕。

## 建置
用 Android Studio（Giraffe 以上）開啟本資料夾 → Build > Build APK。

## 使用
1. 安裝後開啟 App，點「開啟無障礙服務設定」，啟用「彈出廣告自動關閉」。
2. 預設規則涵蓋常見的跳過／關閉文字與 viewId。
3. 遇到關不掉的廣告：先停在該廣告畫面 → 回 App →「從最近畫面加入規則」選按鈕；
   若按鈕抓不到，用「新增規則」填入廣告上的文字當觸發條件，加上 X/Y 比例座標（0~1，
   相對螢幕寬高，因此換解析度也適用）。
4. 「排除的 App」預設含系統介面、設定、輸入法與 LINE，可自行調整。

## 懸浮視窗與圖示化新增
- 主畫面開啟「顯示懸浮視窗」：螢幕邊緣出現 ✕ 小圓點，點開成面板；
  面板可拖曳（放開自動吸附到左右邊）、右下角「◢ 縮放」調整大小、「—」收回成圓點。
- 面板「選取關閉鈕」：到廣告畫面點 X 即自動建立規則（有無障礙節點就記節點，否則記螢幕比例座標＋視窗類別，並等待 5 秒再點）。
- 工作資料夾（公事包圖示）裡的 App：無障礙服務屬於各自的資料夾，需在該資料夾內也安裝並啟用。
